reIDM Integration

Lets the reIDM download manager take over the browser's downloads. Independent of Tonec's IDM extension.

Taking over downloads

Take over browser downloads
When the browser is about to download a file, reIDM downloads it instead. The browser holds the download — without showing it — until reIDM has fetched the first byte, and keeps it if reIDM cannot, so nothing is ever lost.
Take file links before the browser opens them
A click on a link that names a file type below goes straight to reIDM; the browser never requests it. Hold Alt while clicking to let the browser have a link.
Every download, whatever its type
Off: only downloads whose name has one of the file types below.
Also in incognito windows
Needs "Allow in incognito" on the extension's details page as well. Off by default: reIDM keeps a history of what it downloaded.
Always left to the browser: form submissions (POST), files a page builds itself (blob:, data:), and downloads started by other extensions.

reIDM

Start reIDM when it is not running
Uses the com.zektopic.reidm helper that reIDM registers with your browsers. Without it, downloads stay with the browser until reIDM is started.

Finding media

Look for video and audio
Watches the page's network requests for streams and media files (HLS/DASH manifests, mp4, webm, audio), by address and by the type the server reports, and lists them in the popup and the quality picker.

Requests to reIDM are made from the extension's service worker, so they carry a chrome-extension:// origin. reIDM accepts only extension origins and local processes on that endpoint, which is what keeps ordinary web pages out. Cookies are read only for the address being handed over, at the moment it is handed over.
